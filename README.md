# 🐍 Exercícios de Python 3 — Curso em Vídeo

Repositório com os exercícios e desafios práticos desenvolvidos durante a formação de **Python 3 (Mundos 1, 2 e 3 — 120 horas)** ministrada pelo Prof. Gustavo Guanabara ([Curso em Vídeo](https://www.cursoemvideo.com/)).

## 📚 Conteúdos Praticados

- **Mundo 1 — Fundamentos:** Entrada e saída de dados, tipos primitivos, operadores aritméticos, manipulação de strings, módulos e condições simples (`if`/`else`).
- **Mundo 2 — Estruturas de Controle:** Condições aninhadas (`elif`) e estruturas de repetição (`for`, `while` e controle com `break`).
- **Mundo 3 — Estruturas Compostas e Modularização:** Tuplas, listas, dicionários, funções, modularização de código e tratamento de erros.

## 💻 Exemplos de Práticas no Repositório

- Conversor de bases numéricas (binário, octal e hexadecimal)
- Simulador de condições de pagamento e cálculo de descontos/juros
- Análise de estatísticas de compras e gestão de notas com laços de repetição

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3
- **Ferramentas:** VS Code, Git e GitHub
